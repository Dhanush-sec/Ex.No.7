Algorithm
Define the objective – reorganizing daily tasks efficiently using AI.

Input current agenda with tasks and scheduled times.

If unexpected cancellations occur:

Provide updated agenda to the AI.
Prompt the AI to reorganize the schedule dynamically.
AI reviews the agenda, optimizes the schedule, and:

Re-prioritizes critical tasks.
Suggests new opportunities (e.g., extra work, learning, or rest).
Output: A reorganized, optimized agenda with actionable recommendations.

Prompt (Program Simulation)
User Prompt: "During a busy day, if a couple of scheduled tasks get canceled unexpectedly, review my remaining agenda and instantly reorganize my schedule to optimize my time. Recommend new priorities or suggest opportunities for rest."

Example Input Agenda (Before Cancellation)
09:00 – Team meeting  
11:00 – Client call  
13:00 – Lunch  
15:00 – Project work  
17:00 – Gym session  
Cancelled Tasks:
09:00 – Team meeting
11:00 – Client call
AI-Generated Output (Reorganized Agenda)
09:00 – Deep work on project (shifted earlier to maximize focus)  
11:00 – Review notes & prepare presentation slides  
13:00 – Lunch break  
14:00 – Catch up on pending emails and admin work  
15:30 – Continue project work  
17:00 – Gym session (unchanged)  
19:00 – Relaxation or short learning module (self-improvement)  
Recommendations from AI:
Use freed-up morning time for focus-heavy tasks.
Keep lunch and gym unchanged for balance.
Add rest or learning opportunities in the evening.
