# Aim: To develop a prompt-based application using ChatGPT - To demonstrate how to create a prompt-based application to organize daily tasks, showing the progression from simple to more advanced prompt designs and their corresponding outputs.

---

### **AI TOOLS REQUIRED:**

* ChatGPT (Large Language Model)
* (Optional) Simple user interface or command-line system for interaction

---

### **EXPLANATION:**

Large Language Models (LLMs) such as ChatGPT can be leveraged to build interactive, prompt-based applications that adapt to user needs. In this experiment, we design a **personal productivity assistant** capable of managing daily tasks, scheduling events, providing wellness tips, and answering general queries in natural language.

This assistant demonstrates **prompt engineering**, user adaptability, and basic task automation—all powered by AI-driven text generation and understanding.

---

### **PROMPT:**

 “Design a personal productivity assistant that can help manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries. The assistant should interact using natural language and be adaptable to the user’s changing preferences over time.”

---

### **PROCEDURE:**

1. **Define Core Requirements:**

   * Identify key functions: task management, scheduling, wellness tips, and general queries.
   * Determine adaptability features (e.g., preference learning or response personalization).

2. **Construct Prompts for Each Function:**

   * **Task Manager Prompt:** “Add a task to call mom at 6 PM.”
   * **Scheduler Prompt:** “Schedule a meeting with the team tomorrow at 10 AM.”
   * **Wellness Prompt:** “Give me a tip to stay productive today.”
   * **Query Prompt:** “What are the best techniques for stress management?”

3. **Simulate User Interaction:**

   * Use ChatGPT or a command-line interface to test the prompts.
   * Observe how the model responds to natural language input and adjusts based on context.

4. **Feedback and Adaptation:**

   * Refine prompts for clarity and better context handling.
   * Optionally simulate user preference memory (e.g., user prefers morning reminders).

5. **Output Generation:**

   * Collect responses generated by the LLM for each prompt.
   * Document the final interactive outputs of the assistant.

---

### **EXPECTED OUTPUT:**

**Personal Productivity Assistant Features:**

#### 1. **Daily Task Manager:**

* Accepts tasks using natural language.

 “Remind me to call mom at 6 PM.”
* Organizes tasks by **priority** and **deadline**.
* Provides **daily summaries** and lists of pending tasks.

#### 2. **Smart Scheduler:**

* Creates and manages calendar events.
* Understands overlapping appointments and free time slots.
* Provides friendly reminders or rescheduling options.

#### 3. **Wellness Tips Generator:**

* Suggests daily wellness tips (e.g., “Take a 5-minute walk after lunch”).
* Adjusts suggestions based on past user feedback or preferences.

#### 4. **General Query Handler:**

* Answers common questions (e.g., “How can I improve focus?”).
* Offers context-aware suggestions for productivity and wellbeing.

* Learn **prompt engineering techniques** for efficient user-AI interaction.
